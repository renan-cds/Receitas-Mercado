# Receitas-Mercado

Aplicativo web de estoque doméstico de mantimentos integrado a receitas culinárias.

**Status:** planejamento. Não há código de produção neste repositório até a aprovação do documento abaixo.

- Documento canônico: [docs/PLANEJAMENTO.md](docs/PLANEJAMENTO.md)
- Restrição do MVP: custo operacional zero (OSS + auto-hospedagem + IA opcional BYOK)

Após a aprovação das premissas e das decisões pendentes da seção 14, a implementação começa pela etapa E0 (Docker Compose, API, PWA).
